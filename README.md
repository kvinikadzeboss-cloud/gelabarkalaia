# Student Grade Tracker

A command-line Python application for tracking student grades across three progressively featured versions.

---

## Versions

### Version 1 — Basic Tracker
The simplest form of the tracker. Stores one grade per student in memory.

**Features:**
- Add a student with a single grade
- View all student grades
- Calculate class average

---

### Version 2 — Enhanced Tracker
Builds on v1 with grade quality info and basic analytics.

**Features:**
- Everything in v1
- Letter grade conversion (A–F)
- Input validation (grades must be 0–100)
- Remove a student
- Show the highest and lowest scoring students

**Letter Grade Scale:**

| Grade | Letter |
|-------|--------|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| 0–59 | F |

---

### Version 3 — Full-Featured Tracker
The most complete version. Supports multiple subjects per student and persistent storage.

**Features:**
- Everything in v2
- Multiple subjects per student
- Save data to `grades.json` and reload on startup
- Detailed per-student grade reports with subject breakdowns
- Class summary with top student and student needing support

**Data is saved to:** `grades.json` (created automatically on first save)

---

## Requirements

- Python 3.x
- No external libraries required (v1 and v2)
- v3 uses `json` and `os` from the standard library

---

## Usage

Run any version directly with Python:

```bash
python grade_tracker_v1.py
python grade_tracker_v2.py
python grade_tracker_v3.py
```

Each version presents a numbered menu. Follow the prompts to add students, view grades, and explore summaries.

### Example (v3)

```
=== Student Grade Tracker v3 ===

1. Add Grade
2. Remove Student
3. View All Grades
4. Class Summary
5. Save & Exit

Choose an option: 1
Student name: Alice
Subject: Math
Grade (0-100): 92
Added Math grade 92 (A) for Alice.
```

---

## Notes

- Data is stored **in memory only** in v1 and v2 — it is lost when the program exits.
- In v3, data persists between sessions via `grades.json`. Always use **option 5 (Save & Exit)** to preserve changes.
- All versions validate that grades are between 0 and 100.
